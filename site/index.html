How to read it

Harness
What runs around the coding agent. Default is the agent alone; peer review is squiz reviewing each change the agent makes, with a fixer that answers the findings.
Runs
How many times the arm ran every task, one trial per task each time. Rates pool all runs; cost and time are per run.
Resolved rate
Resolved trials over valid trials, with its 95% interval.
pass@k
The share of tasks that at least one of the arm’s k runs resolved.
Timed out
Trials stopped at the agent’s time limit, counted as unresolved.
Tokens / trial
The median tokens the agent read and wrote in one trial, cached reads included: a rough size of the task.
Cost
AI credits at $0.01 each for Copilot CLI, Anthropic’s API price for Claude Code. A price, not what was paid.
