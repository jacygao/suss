How to read it

Resolved rate
Resolved trials over valid trials, pooled across an arm’s runs, with its 95% interval. A timed-out trial counts as unresolved.
pass@k
The share of tasks that at least one of the arm’s k runs resolved.
Cost and agent time
Per run. Cost is AI credits at $0.01 each for Copilot CLI and Anthropic’s API price for Claude Code: a price, not what was paid.
Tokens / trial
The median tokens the agent read and wrote in one trial, cached reads included.
Peer review
squiz reviews each change the coding agent makes, and a fixer answers its findings.
