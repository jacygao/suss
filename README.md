# SWE-drill

Run your own evals for AI coding agents and harnesses. Built on
[Harbor](https://github.com/harbor-framework/harbor), SWE-drill puts Copilot CLI,
Claude Code and others through the eval datasets research labs publish, grades
every patch in a fresh sandbox, and ranks which harness and model hold up on a
leaderboard of your own.

See ours at [jacygao.github.io/swe-drill](https://jacygao.github.io/swe-drill/).
Its numbers and how they were made are in
[docs/leaderboard/](docs/leaderboard/README.md).

The specification is [docs/specs/swe-drill-spec.md](docs/specs/swe-drill-spec.md).
